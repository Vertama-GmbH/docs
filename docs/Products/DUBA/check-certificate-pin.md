# Check a Certificate PIN

!!! info "German only"
    This documentation is currently available in German only:
    [Zertifikats-PIN prüfen](/de/Products/DUBA/check-certificate-pin/).

How to check on your own computer, with the tools Windows, macOS and Linux
bring along, whether a PIN opens a postbox certificate file (`.p12`) — before
registering the postbox in V.ap, or when V.ap refuses the registration with
a wrong-PIN message.
