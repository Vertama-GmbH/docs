# V.ap Fremdaufruf URL-Builder

!!! info "German only"
    This documentation is currently available in German only:
    [V.ap Fremdaufruf URL-Builder](/de/V.connect/Fremdaufruf/url-builder/).

The URL-Builder is a V.ap feature that generates URL templates for pre-filling
V.ap forms from a hospital information system (HIS/KIS). You pick a product
module and form, mark the fields the KIS should supply, and copy the resulting
template into the KIS configuration — the KIS substitutes its own placeholders
at call time.

It builds the URLs consumed by the V.connect Fremdaufruf component; see the
[Fremdaufruf overview](overview.md) for how the component fits together.
